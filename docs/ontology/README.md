# 本体论学习库（Ontology Lab）

> 用「专访 1.0」这个真实系统当练手载体，**边重构边把本体论从头学到尾**。
> 这里存放所有与本体论相关的讨论、方案、笔记。每一次讨论都落成文档；每一篇文档都把**理论知识**与**本系统的实践**详细结合讲解——学一个概念，就在代码里指出它对应什么、怎么用、怎么改。

---

## 0. 这个文件夹是干什么的

- **目标**：系统性地掌握本体论（哲学起源 → 计算机科学的形式本体 → 知识图谱工程），并且每一块知识都在「专访 1.0」里落地一次，做到"学过 = 用过"。
- **载体**：专访 1.0 本质是"为用户构建个人认知知识图谱"的产品，天然适合用本体论重构——它已经有一套**隐性本体**（散落的实体 + 三套不一致的关系编码），我们的任务就是把它**显式化、规范化、可推理化**。
- **产物**：一系列编号文档（理论×实践）+ 一套术语表 + 一条可执行的重构主线（P0→P3）。

## 1. 文档约定

1. **每次本体论讨论 → 一篇文档**，放进本文件夹，按 `NN-标题.md` 编号。
2. **每篇文档遵循"三段式"教学结构**，确保理论不悬空、实践不盲目：
   - **理论**：这个概念是什么、从哪来、形式定义、在学术/工业界的标准表示。
   - **项目映射**：它对应专访 1.0 的哪些真实类型/字段/函数（给出 `file:line` 或类型名）。
   - **动手**：基于它，我们要在系统里建/改什么（可落到重构主线的某个阶段）。
3. **术语首次出现给中英对照**，并登记进 [99-术语表](99-术语表.md)（哲学义 / CS 义 / 本项目义 三栏）。
4. **诚实优先于优雅**：凡是"理论上更高级但本场景用不上"的（如 OWL 全量推理），明确说明为什么不用，并给出轻量对应物。这条纪律贯穿全库。

## 3. 重构主线（与学习路线交织）

学习不是纸上谈兵，每学一块就推进一步真实重构。主线见 [01 总纲](01-本体论重构总纲-理论与实践.md) §7：

- **P0** 写本体规范（学完 01–03 即可动手）——零运行时风险。
- **P1** 引入 `Relation` 统一边模型，吞掉 `EvidenceAnchor`/`relatedThemeIds`/`MemoryEdge` 三套编码（学完 02/03/09）。
- **P2** 召回/时间线/主题聚合改走统一图（学完 06/08）。
- **P3** 公理校验器 + 轻量推理（学完 04/05/07/11）。
- **P4**（可选）收敛 25 数组——默认不做。
