## 分类标准

- **A 类 = 静默假装成功**：失败被掩盖，产出物与成功时不可区分，无任何用户可见标记（多数连日志都没有）。→ 剔除的头号目标。
- **B 类 = 有标记的降级**：失败后仍产出替代结果，但带 `degraded` 标志 / `aiRunEvent(status:"degraded")` / 结构化日志。→ 需产品决策：是保留标记式降级，还是连降级本身都剔除（失败直接 4xx/5xx）。
- **C 类 = 合法错误处理**：fail-fast、如实 4xx/5xx、诚实空态、安全归一化。→ 保留。

## 全局结论（先读这段）

1. **"离线兜底"是被设计进系统的，不是意外**。需求清单里明文存在 `REQ-INTERVIEW-TURN-OFFLINE-FALLBACK`；确定性策略引擎、确定性 finalize、离线模板分析、local-demo 搜索 provider 是一整套平行实现。剔除它们不是删几个 catch，而是反转一项产品决策。
2. **可观测性有三档，只有一档真正"暴露"**：
   - `aiRunEvent(status:"degraded")` 写进 state → 前端可见。**只有 finalize / pre_signals / interview_turn 三条路径 + 少数语音路径达到这档。**
   - `console.warn` 结构化日志 → 只有运维看得到，用户无感。绝大多数 B 类停在这档。
   - 什么都没有 → A 类。
3. **共 22 处 A 类**、约 40 组 B 类、50+ 处 C 类。历史审计确实修掉了大量静默降级（409 丢编辑、persist banner、needs-review 标记等均已闭环），残留的 A 类集中在：LLM 输出打捞/模板填充、SurrealDB 召回内部回落、离线本地回退假成功、persist 异步契约、数据钳制。
4. **两条架构级 A 类需要单独设计**（不是简单改 throw）：persist 异步 200（A-18）和 clamp 数据钳制（A-19）。

## 剔除路线建议（按风险/收益排序）

**第一批：纯剔除，无产品争议（A 组 1+2 的大部分）**
- A-1/A-2/A-3/A-5/A-6/A-7：LLM 缺字段 → 改为抛错（进各自已有的 B 强档降级通道，或直接 fail 请求）。
- A-4 parseJsonObjectLoose：截断打捞至少要打标记上抛"截断"事实；严格模式下直接 fail。
- A-8 静默截断：改为超长即抛错或如实记录截断事实。
- A-9~A-13 召回内部回落：统一补日志或上抛（与同函数 catch 分支对齐即可，改动极小）。
- A-14/A-15：对齐已有的 needs-review / degraded 标记（不对称遗漏，补齐即可）。

**第二批：语音链路（A-16/A-17）**
- agent 拿不到上下文时拒绝开场或明确播报，而不是静默变"陌生人"。这是单点最伤产品价值的一条。

**第三批：前端离线三连（A-20/A-21/A-22）**
- 直接剔除 `isNetworkError` 后的本地回退，离线即报错（或至少对齐 autoBrief 的"本地占位"警告）。同批决策：local-demo 搜索 provider（连 B 强档那条一起）是否整体删除——它的产物本质是捏造数据。

**第四批：架构级（A-18/A-19，需设计）**
- A-18 persist 异步 200：选项 a) 写路径 await 落库确认（延迟上升）；b) 响应携带 `persisted:false` + 前端跟踪；c) 保持现状但把 persist 失败升级为对后续写请求返回 503（degraded 熔断）。
- A-19 clamp 钳制：写入侧改 422 拒绝；读回侧遇畸形至少响亮告警（读回侧直接抛会让老数据永久锁死，需迁移配套）。

**B 弱档统一动作**：把"仅 console.warn"的降级全部升级为 aiRunEvent(degraded) 或响应级 degraded 标志（复用 finalize 已有的机制），使"暴露"贯穿到用户面。之后再逐条决策哪些连降级产物都不要。

**同批应清理的配套物**：确定性平行实现（`buildFallbackPreSignals`、确定性 finalize、`analyzeImportedInterview`、`buildDeterministicReviews`、local-demo provider、`_FALLBACK_INSTRUCTIONS`）在对应降级剔除后即成死代码，需求 `REQ-INTERVIEW-TURN-OFFLINE-FALLBACK` 需同步作废，相关测试（大量测试专测降级路径）需同步删改。
