## 2. 正式发现 · P1（开放）

### P1-1 · PARTIAL · 生产 bootstrap 无凭据分发长期共享密钥

- **位置**：`apps/api/src/server.ts` `registerRuntimeBootstrap`；`src/main.tsx` → sessionStorage/window  
- **触发**：`DEPLOYMENT_PROFILE=production` + 已设 token；任意客户端 `GET /api/runtime-bootstrap`  
- **影响**：SPA/WS **可用**（07-22 P0 已修），但「能打到 API 的人即可领同一密钥」；XSS 可读 sessionStorage  
- **证据**：CODE-CONFIRMED + `server.test.ts` runtime-bootstrap 段  
- **修复方向**：短命 session、仅 HttpOnly cookie 不回 body、同源 CSRF 绑定、或设备配对码

### P1-2 · OPEN · 若干业务写路径仍裸 `replaceState`（无 `confirmPersisted`）

| 位置 | 场景 |
|---|---|
| `routes/realtime-voice.ts` ~356, ~517 | 语音 interrupt / record-turn |
| `routes/import.ts` ~65 | 文档导入 |
| `routes/corpus.ts` ~128 | 语料分析 |

- **影响**：surreal 异步落库失败窗口内仍可能「HTTP 成功、重启丢」  
- **主路径已 durable**：PUT state、interview-sessions、chat、search、podcast、memory-candidates、`runStateCommand`
