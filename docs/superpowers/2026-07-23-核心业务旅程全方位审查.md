## 0. 执行摘要

### 一句话

系统已具备完整的 **专访 → 沉淀 → 记忆 → 调研 → 问答 → 再生产 → 治理** 业务闭环，且多处已做「诚实失败 / durable 写 / 上下文门禁」；当前最大风险不在「有没有功能」，而在 **权威状态并发写模型**、**产品语义与实现双标**、**跨旅程数据归属/回访断链**。

### 全局 Top 风险（跨旅程）

| # | 风险 | 主要波及旅程 | 为何爆炸半径最大 |
|---|---|---|---|

## 1. 实时专访

### 流程

```text
开始 → create(session+prefetch)
  ├─ 文本 /turns（策略+LLM+guide 回写）
  ├─ 级联 cascade → 仍走 /turns
  ├─ Omni → record-turn + voice-instructions + pre_signals
  └─ LiveKit → agent-context + record-turn
结束 → finalize + 冷层降冷 + 可选音频
```

### 关键 findings

| ID | 级 | 标题 | 爆炸半径 |
|---|---|---|---|
| **IV-P0-01** | **P0** | `voice-instructions` 仍写锁豁免却整态 replace；与 `record-turn` 竞态可丢轮 | turns → finalize/记忆/冷层/UI/跨会话 |
| **IV-P0-02** | **P0** | `GET agent-context` 读路径整态写；LiveKit 同构丢轮 | 同上 + Python agent |
| **IV-P1-01** | P1 | cascade barge-in Abort 不取消服务端 `/turns` 落库 → 幽灵全文 | 归档污染、记忆污染 |
| **IV-P1-02** | P1 | 生产 LiveKit agent 无 Bearer → agent-context 失败 | LiveKit 生产不可用 |
| **IV-P1-03** | P1 | Omni/LiveKit 默认无 strategyTrace → 质量门系统性虚低 | 质量分、护栏学习 |
| **IV-P1-04** | P1 | doNotSave 仍跑完整 finalize LLM；审计写「生成笔记」 | 隐私边界、成本 |
| **IV-P1-05** | P1 | /end 长临界区与无锁中场写交错 | 末轮丢失 |
| **IV-P2-*** | P2 | control 不拦 offloaded；decisions 审计写原话；冷热非事务；pre-signals 持锁过久 | 分叉/合规/延迟 |

### 最大爆炸半径（本旅程）

1. 权威 turns 被 clobber  
2. 打断幽灵轮进入跨会话资产  
3. 三语音栈质量不可比

## 11. 分旅程修复优先级（建议，不改码）

### 批次 α — 数据权威（专访 P0）
1. 撤销/重写 voice-instructions 写锁豁免；CAS 合并 guide，禁止旧 turns 覆盖  
2. agent-context 禁止 GET 整态写；只读或写门内字段 merge  
3. 会话级串行 + 并发测试：record-turn ∥ voice-instructions  

### 批次 β — 回访与 HITL 主价值
4. Track 继续传 topicHint（端到端）  
5. approve merge/add 双模式；默认不丢候选文案  
6. consolidate：仅对已摘要簇 deprecate；摘要 approve 替换 keeper  

### 批次 γ — 写路径与导入可用性
7. search/import/chat 外网 IO 出锁（对齐 auto-run 模式）  
8. lastRefreshedAt 对齐；议程去硬编码  
9. 敏感粒度下沉；knowledge 按 ragChunks 多块索引  

### 批次 δ — 产品诚实与配置
10. Playbook/播客/doNotSave 文案与行为对齐  
11. reviews 改 POST/缓存/独立预算  
12. health/capabilities/鉴权假绿收口  

### 批次 ε — 语音质量与打断
13. /turns 可取消或不落库；cascade interrupt 语义  
14. Omni/LiveKit 补 strategy 或明确质量门「不适用」  
15. LiveKit agent 注入 token
