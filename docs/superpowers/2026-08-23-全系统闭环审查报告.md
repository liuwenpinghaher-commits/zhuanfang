## 6. 爆炸半径图（四条源）

```text
session.turns
  → /end finalize → notes / points / questions / decisions / debts / memoryCandidates
  → 降冷 raw_material（热态 turns 变空）
  → 专访召回 / 档案徽章 / 播客来源 / 复盘计数
  写脏（幽灵全文、缺主持句）= 以后每一场都按假档案问

memoryRecords
  → 下一场 prefetch / voice-instructions / 资产对话
  「仍新增」实际 merge、矛盾当普通确认
  = 跨时间问错人

importSources + ragChunks + knowledge index
  → 资料问答 / 专访 ragHits / chat
  双索引不一致 = 一边问得到一边问不到
  导入终写占锁 = 对话/结束一起饿死

ProductState.revision（整本 PUT / 分析终写 / auto-briefs 旧快照）
  → 盖掉刚写入的 turns、候选、简报
  半径 = 全库
```

脏数据能流到哪：**turns 是最大源头**；其次是 **整本 replace 的分析/自动简报**；再次是 **记忆 merge 假按钮**。复盘/红灯假闭环不写脏数据，但会让人看不见已经写脏。
