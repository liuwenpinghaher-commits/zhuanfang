# 系统配置审查

**日期**：2026-08-23  
**范围**：`ConfigView` + `PATCH/GET /api/system/config` + `GET /api/system/capabilities` + `ProductState.systemConfig`  
**方法**：当前代码 + demo 只读探活（未改密钥、未改库路径）  
**demo**：`https://zhuanfang.example.com` health 200；config/capabilities/PATCH 未登录 401

## 总判

一半真一半样子，钥匙那半边在生产上还危险。

不是「这一页写坏了所以全不能用」。搜索、记忆开关、语音档、追问深度、调研定时，有一批格子拧了下一场真会变。但同一页还摆着不会转的 TTS 厂家、模型名、留白、引导，保存产品策略还不走版本历史。服务端密钥谁登录都能改，改完写进容器里一份会随重启丢掉的文件——灯绿、toast 成功，整站钥匙其实没换牢。

## 人话（给用户看）

- 拧了会变的：默认搜索（百炼/AnySearch）、敏不敏感进对话、实时语音走级联还是直通还是 LiveKit、级联开口的声音、播客默认声、追问能挖多深、会不会把网上搜来的带进专访、后台要不要定时搜。
- 拧了是样子的：选 Local Demo 搜索会被写回百炼；选 OpenAI / ElevenLabs 合成不会真换厂家；页面上的模型名不是真正在打的模型；「留白阈值」「主动引导」基本不指挥级联语音；配置版本回滚页面上没有。
- 千万别在页面上动的：密钥、存储路径。现网已登录就能改整站钥匙；改完看起来成功，容器一重建又回到服务器上那份旧钥匙。

## 服务端 env（钥匙）

保存：`ConfigView.saveRuntimeConfig` → `PATCH /api/system/config` → 白名单 key 写入 `writeEnvFileUpdates` + 改进程 env → `refreshProviderClients`（`system.ts:353-388`，`server.ts:645-680`）。密钥 GET 不回明文（`value: null`，mask「已配置（••••）」）。空提交 422。必填密钥清空 422。非白名单 key 丢弃。

demo 实证（2026-08-23）：

- 未登录 GET/PATCH config、GET capabilities → **401**
- 容器 `PRODUCT_ENV_FILE` **空**
- 容器内 **没有** `/app/.env.local` / `.env.production.local`
- compose **未**挂 env 文件进容器，只在启动时把宿主 `.env.production.local` 打进 `environment:`

因此：页面保存会在容器里**新建** `/app/.env.local`，并立刻改进程内客户端；**容器重建后这份文件消失，钥匙回到 compose 启动时那份。** `PRODUCT_STATE_DB_PATH` 标了重启才生效，文案有；改它不能热切库，但 toast 仍说已保存。

`refreshProviderClients` 会重建搜索/专访/TTS/转写/embedding/realtime/声音复刻客户端。改模型名/key 一般立刻变。存储路径不会热切。

## 闭环三句

1. **换默认搜索**：选百炼/AnySearch 并保存，下一份简报走新这家（CODE-CONFIRMED，`search.ts`）。选 Local Demo → 落库被改回百炼（CODE-CONFIRMED，`storage.ts:906`）。假闭环。
2. **关掉敏感记忆进上下文**：下一场 turns/chat/召回按最新 state 过滤（CODE-CONFIRMED）。真闭环。
3. **改实时模式**：下一场 `useRealtimeVoiceControls` 按新档接线（CODE-CONFIRMED）。进行中的场不换。真闭环（下一场）。

## 断点

- 产品策略保存：本地 setState 立刻 toast 成功，真正落库靠 autosave PUT。409/离线时用户以为已经改了规矩。
- 服务端配置：进程内立即生效；demo 落盘不进宿主 env，重启回滚。
- 红灯 provider 仍可保存，只在字段下给警告。
- 改 `realtimeMode` 不踢当前语音会话。
- 调研间隔改完要等当前 timer 到期（`scheduleNext` 用新间隔排下一次）。
- `PATCH /api/system/config` 不在写门豁免名单 → 整段持锁做文件 IO。不是假成功，但是会挡别的写。

## 发现

### P1 · 生产页能改整站钥匙，而且改不牢

- **现象**：已登录用户打开「参数」就能改 DASHSCOPE 等；保存 toast 成功。demo 容器没有 `PRODUCT_ENV_FILE`，也没有挂载宿主 `.env.production.local`。
- **证据**：`system.ts:353-388`；`server.ts:353` 默认写 `cwd/.env.local`；`server.ts:878` 只有设了 `PRODUCT_ENV_FILE` 才改路径；`docker-compose.yml` 无该变量。demo `printenv PRODUCT_ENV_FILE` 空；`/app/.env*` 不存在。
- **拧哪一格**：服务端配置里的密钥/模型/地址。
- **下游**：立刻 refresh 客户端（进程内真变）；重启/重建容器回到 compose 启动值。多人共用这一台 API 时，一人改钥匙全站跟着走。
- **反驳**：未登录 401，不是匿名可改。仍成立：登录面 = 运维面，且持久化是假的。
- **等级**：P1 CONFIRMED（demo 路径）+ CODE-CONFIRMED（写盘逻辑）

### P1 · 产品策略「已保存」发生在服务器点头之前

- **现象**：`saveProductConfig` 直接 `setProductState` 并成功 toast，不调用域版本函数，不等 PUT。
- **证据**：`App.tsx:1609-1619`。对比运行配置走 `updateSystemConfig` 且失败有中文原因。
- **拧哪一格**：任意产品策略。
- **下游**：autosave 409/离线时，界面规矩和书里规矩会分叉。
- **反驳**：多数在线情况随后 PUT 成功。仍成立：成功语义是假的。
- **等级**：P1 CODE-CONFIRMED

### P2 · 一页里有一批不会转的格子

- TTS `openai`/`elevenlabs`：无 client，仅改灯的 `active`（`system.ts:479`）。前端包现网仍含「OpenAI」「ElevenLabs」。
- `models.*` 不决定真正模型。
- 搜索 `local-demo` 被 normalize 写回百炼。
- 留白阈值几乎只改面试页旁白；cascade 用自己的停顿。
- 主动引导：Omni 写死开启；cascade 不走该引擎。
- 引导频率写入 policy 无人读。
- **等级**：P2 CODE-CONFIRMED（TTS 选项 CONFIRMED 现网包）

### P2 · 配置版本回滚是死功能（对这页）

- `withSystemConfigVersion` 存在，配置页保存不用它。
- 页面无历史、无回滚。
- 语料补丁仍会写 `configVersions`，用户会在状态页看到版本号漂，却不是自己拧螺丝留下的。
- **等级**：P2 CODE-CONFIRMED

### P2 · 能力灯有常绿装饰项

- `voice-endpointing-pvad`、`voice-livekit-interrupt`：`status:"ready", active:true` 写死（`system.ts:559-577`），与当前 `realtimeMode`/是否真开 pVAD 无关。
- `bailian-character.active` = `Boolean(interviewModel)`，有字符串就亮「当前启用」。
- CosyVoice `active` 跟 `ttsProvider===bailian` 绑，选 OpenAI 会显示未启用，合成仍可能用百炼。
- **等级**：P2 CODE-CONFIRMED

### P2 · 三处音色互不认账

- 产品默认访谈声、产品播客声、env `BAILIAN_TTS_VOICE` / `BAILIAN_REALTIME_VOICE`、播客工作台本地 state。
- 级联开口吃产品 `defaultVoice`；Omni 吃 env 实时声；播客新一期吃产品播客声。
- **等级**：P2 CODE-CONFIRMED

### P3 · GET config 把 env 文件路径回给浏览器

- `buildRuntimeConfigResponse` 含 `envFilePath`；页面渲染「Env 文件：…」。
- 未登录 401，已登录可见容器路径。
- **等级**：P3 CODE-CONFIRMED

### P3 · 清理重复生成物是本地去重，不是配置

- `dedupeGeneratedArtifacts` 按业务键留一份；走 setState。可能删重复简报/播客/语料，不碰手写观点。放在配置「状态」页容易让人以为在清配置。
- **等级**：P3 CODE-CONFIRMED

## 明确不是问题

- 敏感记忆、待审进上下文、后台定时调研默认关，且页上写了默认关。有意关闭。
- 密钥 GET 不回明文，mask 不含尾 4 位。
- PATCH 白名单，未知 key 丢弃。
- 必填密钥不允许空值清空。
- 未登录改配置 401（demo 实证）。
- `useLayer2Endpoint` 默认关，属实验档。
- 外部素材记忆策略默认审查后才确认，页上没给开关偏安全。
