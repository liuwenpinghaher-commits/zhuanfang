## 人话（给用户看）

- 点了会发生的：今日台开一场（题目会带上）；继续未完成；扔掉还没说话的空场；打字发出去失败会把原文还你；结束会生成笔记；勾了不保存就真不写档案、不上传录音；从主题「接着访 / 用此主题开始」会带上这条线。
- 点了是样子的：今日台「将带入 · 主题线」在你改了题目时仍显示，但开场不一定带那条线；「新建主题线」并不会新建一条主题，只是用长期模式开一场；侧栏「不追」这个决策/债只改你屏幕上的本场，下一问服务端可能还追。
- 谈的时候注意：打字和级联语音，调节键（放慢、换角度、不保存）会进下一问；百炼直通开口时，调节键多半只在对话里冒一句系统话，模型下一句不一定照做。

## 闭环五句

1. 今日台开日常复盘：会创建这场并跳进实时专访，题目是你填的或推荐题。**成立。**
2. 打一行发出去：服务端用户句+主持句；失败原文还在。**成立。**
3. 开口：级联能走 ASR→turns→TTS；无场会拦住。抢话本地会停，服务端截断最好努力。**大体成立**（未在 demo 真人开口验证）。
4. 点结束：有用户句才归档；不保存不写笔记。**成立。**
5. 主题接着访：创建带 `relatedThemeIds`。**进场成立**；笔记芯片依赖结束时 LLM 是否把主题写回，**可能掉**（`finalize.ts:190-193` 笔记只挂 LLM 的 themes）。

## 断点

- 开始：连点用 `startingRef` + `clientRequestId` 防双场。已有未完成会先 confirm，选是则再开一场（不顶掉旧场）。
- 发送：空句直接 return；失败不清成功态。文字走 JSON `/turns`，语音级联走 stream。
- 录音：浏览器手势内 resume AudioContext；失败有提示。
- 结束：空场 422 预检；409/404 当已结束并跳笔记——若本场其实是不保存，可能把人送到笔记页（边角）。
- 切页再继续：用内存里的 session，不重新 GET。

## 发现

### P2 · 今日台「将带入主题线」在你改题后仍显示，开场却不一定带上

- **现象**：芯片始终用出现次数最多的主题；真正传入 `relatedThemeIds` 只在题目仍等于推荐题时。
- **证据**：`HomeView.tsx:144-150` 与 `383-397`。
- **点哪个**：开始。
- **书里**：自定义题目的场可能不挂那条线，但你看见「将带入」。
- **反驳**：横排「用此主题开始」是真的。仍成立：主开始按钮旁那颗芯片会骗人。
- **等级**：P2 CODE-CONFIRMED

### P2 · 「新建主题线」不会新建主题

- **证据**：`HomeView.tsx:451-458` 只 `onStart("long-term", selectedTopic)`。
- **等级**：P2 CODE-CONFIRMED

### P2 · 「不追」只改屏幕上的这场，下一问服务端可能还追

- **证据**：`App.tsx:2184-2186` 只 `setSession`；autosave 的是 `productState`；`/turns` 读仓库里的 session。策略跳过依赖 `session.suppressedRevisitIds`（`strategy.ts:318`）。
- **等级**：P2 CODE-CONFIRMED

### P2 · 调节键对百炼直通下一句不一定生效

- **证据**：文本/级联：`bailian/_impl.ts:1279` 注入 pendingControl。语音 instructions：`voice-instructions.ts` 无控制段。直通主持句来自模型开口 + `recordInterviewTurn`，不走 `receiveTurn`。
- **反驳**：对话流里仍有「系统」控制反馈句，用户能看见点过。仍成立：下一问嘴上可能不照做。
- **等级**：P2 CODE-CONFIRMED

### P2 · 从主题进场挂在 session 上的线，结束笔记可能不挂

- **证据**：`finalize.ts:190-193`：completed session 合并 `session.relatedThemeIds`；`finalNote.relatedThemeIds` 只来自 LLM `content.themes`。笔记页用 note 的线。
- **等级**：P2 CODE-CONFIRMED

### P3 · 会中节奏旁白不是真 VAD

- **证据**：`App.tsx` `buildRealtimeTurnState` 的 `silenceMs: recording ? 0 : 900`。配置里的留白已接到 cascade `minPauseMs`，但这块文案仍假。
- **等级**：P3 CODE-CONFIRMED

### P3 · 预约下次只填表

- 文案是预约，不算假成功。易被当成开始。
- **等级**：P3

## 明确不是问题

- 未登录不能建场/说话/结束（demo 401）。
- 文字失败会还输入、能重试。
- 空场不能结束；连点结束 409 当已收尾。
- 不保存：不写笔记/记忆、不上传录音、音频接口拒收；结束文案不谎称有档案。
- 级联不在回调里双写 turns。
- 有未完成再开会先问你。
- 转写待确认确认前不写入。
- 扔掉空场：有用户句的场扔不掉。
