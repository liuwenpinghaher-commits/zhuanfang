# Phase 1 API Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first Product API slice with health, state read, and state reset endpoints so later DB, provider, and Mastra work has a stable backend boundary.

**Architecture:** Keep the current React app unchanged for this slice. Add a Fastify API under `apps/api`, expose `buildApiServer()` for tests and `startServer()` for local development, and put ProductState persistence behind a repository interface so the next slice can swap in Postgres/Drizzle.

**Tech Stack:** Node.js 20+, TypeScript, Fastify, Vitest, existing domain engine.

import Fastify from "fastify";
import { registerHealthRoutes } from "./routes/health";

export function buildApiServer() {
  const server = Fastify({ logger: false });
  void server.register(registerHealthRoutes);
  return server;
}

export async function startServer() {
  const server = buildApiServer();
  const port = Number(process.env.PORT ?? 8787);
  const host = process.env.HOST ?? "127.0.0.1";
  await server.listen({ host, port });
  return server;
}

if (import.meta.url === `file://${process.argv[1]}`) {
  startServer().catch((error) => {
    console.error(error);
    process.exit(1);
  });
}

- [ ] **Step 3: Implement repository**

```ts
import { createInitialProductState } from "../../../src/domain/engine";
import type { ProductState } from "../../../src/domain/types";

export interface ProductStateRepository {
  getState(): ProductState;
  resetState(): ProductState;
  replaceState(state: ProductState): ProductState;
}

export function createInMemoryProductStateRepository(initialState: ProductState = createInitialProductState()): ProductStateRepository {
  let state = initialState;

  return {
    getState() {
      return state;
    },
    resetState() {
      state = createInitialProductState();
      return state;
    },
    replaceState(nextState) {
      state = nextState;
      return state;
    }
  };
}
```
