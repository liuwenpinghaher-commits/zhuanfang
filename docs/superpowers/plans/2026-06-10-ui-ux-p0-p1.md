# UI/UX P0-P1 Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve accessibility, navigation hierarchy, touch usability, operation feedback, and design-token consistency for the current interview product prototype.

**Architecture:** Keep the app as a Vite + React + TypeScript SPA. Add small UI helper models in `src/ui.ts`, test them with Vitest, then wire them into `src/App.tsx` and `src/styles.css`. Do not change the domain engine in this phase.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, lucide-react, CSS.

---

- Create `src/ui.ts`: view grouping, notice model, accessible id helpers.

- Modify `src/App.tsx`: grouped nav, skip link target, visible form labels, action notices, reset confirmation, larger interaction affordances.
- Modify `src/styles.css`: semantic CSS tokens, focus-visible ring, grouped nav, touch target sizes, form field styles, notice styles, reduced-motion handling.

- [ ] **Step 3: Implement UI helpers**

Create `src/ui.ts` with:

```ts
export type View =
  | "home"
  | "interview"
  | "search"
  | "corpus"
  | "podcast"
  | "notes"
  | "assets"
  | "themes"
  | "config"
  | "profile";

export type NoticeKind = "success" | "info" | "warning" | "danger";

export interface UiNotice {
  id: string;
  kind: NoticeKind;
  message: string;
  detail?: string;
}

export interface NavigationItem {
  id: View;
  label: string;
}

export interface NavigationGroup {
  label: string;
  items: NavigationItem[];
}

export const groupedNavigation: NavigationGroup[] = [
  { label: "今日", items: [{ id: "home", label: "今日访谈台" }, { id: "interview", label: "实时专访" }] },
  { label: "素材", items: [{ id: "search", label: "联网素材" }, { id: "corpus", label: "语料学习" }, { id: "podcast", label: "播客工作台" }] },
  { label: "资产", items: [{ id: "notes", label: "双轨笔记" }, { id: "assets", label: "资产库" }, { id: "themes", label: "长期追踪" }] },
  { label: "系统", items: [{ id: "config", label: "系统配置" }, { id: "profile", label: "个人档案" }] }
];

export function buildNotice(kind: NoticeKind, message: string, detail?: string): UiNotice {
  return {
    id: `notice-${Date.now()}-${Math.random().toString(16).slice(2, 8)}`,
    kind,
    message,
    detail
  };
}
```
