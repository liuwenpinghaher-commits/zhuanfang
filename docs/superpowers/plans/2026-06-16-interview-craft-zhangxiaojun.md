# 专访"提问质感"改进方案 —— 以张小珺《商业访谈录》为范本

> 触发：语音专访上来先问"你过得怎么样？"又自相矛盾说"其实刚来没来得及说"，非常不自然。
> 目标：(1) 定位这种不自然的后台机制并修复；(2) 把张小珺的访谈技法编码进产品（语音 + 文字共用），让 AI 主持人从"语音助手腔"变成"准备充分的专访编辑"。

---

## 一、为什么这么不自然（机制诊断，已定位到代码）

### 1. 真正生效的语音 prompt 只有 6 行，而且是个"被遗忘的本地副本"
运行时用的是 `src/App.tsx:1344` 里的**本地** `buildRealtimeVoiceInstructions`（`toggleRealtimeRecording` 在 `App.tsx:940` 调它）：

```
你是一个真正的私人专访主持人。
每次只问一个核心问题，优先追具体事件、真实张力和可验证假设。
本次主题：{title}
为什么现在聊：{whyNow}
建议开场：{suggestedOpening}
不要长篇输出，不要替用户下结论，不要像客服。
```

而 `src/domain/voice-instructions.ts` 里有一个**更丰富**的同名版本（带 guide/历史引用/知识债/盲区/记忆/视角/策略清单）——**它根本没被语音路径调用**。所有会前准备好的上下文（历史原话、待追问的知识债、盲区）**全部没送进语音模型**。这是第一个结构性问题：**两份 `buildRealtimeVoiceInstructions` 分叉，跑的是瘦的那份。**

### 2. 开场没有被"脚本化"，模型被迫即兴
- 语音连接后，客户端会触发 AI 先开口（`src/realtime/bailianWebsocket.ts` 的 `response.create`），**AI 必须说第一句**。
- 但 prompt 里 `建议开场：{suggestedOpening}` 只是**一条上下文**，不是"你的第一句话必须是它"。也**没有任何一句**禁止寒暄。
- 结果：模型有一堆背景、却没有"第一步该干嘛"的明确指令 → 退回到通用对话本能 → 冒出"你过得怎么样？"（通用寒暄）+"刚来没来得及说"（**元话语填空**：模型没有具体动作时，会把自己的"过渡/迟疑"念出来）。

### 3. 缺少"身份接地"
prompt 没告诉模型："你已经做足功课、这是一次有准备的专访、你不是刚到场的陌生人。" 所以模型会演出"我刚来"的人设——典型的 under-specified 开场症状。

> 一句话总结：**不是模型笨，是开场没被脚本化 + 准备好的上下文没送进去 + 没禁止寒暄/元话语。**

### 4. 对照张小珺：她永远不寒暄
她的开场是一段**事先写好的、极具体的画像旁白**（"毕业于清华和斯坦福…2024 加入 Anthropic，2025 跳槽 Google DeepMind…参与 Claude 3.7/4.5/Gemini 3 开发"），然后**立刻进入实质问题**，第一句话就让听众看到观点而非客套。产品现在的语音开场和这个范本是反的。

## 二、张小珺访谈技法清单（10 条，可直接编码进 prompt）

（基于第 140 集"姚顺宇 4 小时访谈"全文系统抽样 + 141 集对照）

1. **开场用画像旁白，绝不寒暄**：先用一段含≥3 个具体事实（公司/时间/方向）的旁白定位嘉宾，再以**实质问题**进入。永不说"你好啊/最近怎么样"。
2. **单词回弹追问**：嘉宾抛出有分量但含糊的词，立刻把这个词钉回去（"想象不到的。""壁垒是模型。"），逼其展开。每个关键词至多放过一次。
3. **追问必指向具体事例**："最近一次电话聊啥了？""你需要什么？""这是哪一年发现的？"——概括性回答下一句必须要具体/数字/例子。
4. **二选一框架逼精确**："是能力问题还是意愿问题？""是产品的事还是模型的事？"——打破"两者都有"的安全地带。
5. **抓矛盾不放**："可你说 AI 没有个人英雄主义，现在一个 AI 研究员价格炒得跟球星转会一样。"——说了 A 做了非 A，必点出。
6. **每次暖化后立刻钩回实质**：可以调侃/问日常（"最近还频繁打电话吗？"），但下一句必须是实质问题，轻松话题不超过两个来回。
7. **用一句话替嘉宾总结，让他确认/纠正**："所以你其实是在普通班和竞赛班里义无反顾选了竞赛班。"——给听众设检查点，嘉宾要么强化要么产出新信息。
8. **用身份/位置当追问锚点**："作为一线研究员…""作为同时待过 A 和 B 两家的人…"——让问题只有这个嘉宾答得了，逼出独家视角。
9. **代表听众说"我不懂"，但提具体问题**："我也不懂量子物理，大家别骂我"消解权威感，紧接一个**具体**问题，让科普以问答而非演讲进行。
10. **结构弧线 + 显式转场**：新闻热点 → 个人成长叙事 → 价值观 → 轻量收尾；进入新弧段显式宣告（"在进入今天主题之前…""那接下来…"）。

**两条贯穿性铁律**：① 不问"你怎么看 AI 的未来"这种开放大题，永远先给一个具体现象/争议再问判断；② 不允许嘉宾用"很难说"结束，立刻给二选一或具体条件续上。

## 三、改进方案（分优先级）

### P0 —— 修语音开场（最高杠杆，半天内可做完）

**P0-1 重写语音系统 prompt（脚本化开场 + 禁寒暄/元话语 + 身份接地）**
把 `App.tsx:1344` 的 6 行换成下面这版（并把会前上下文真正注入）：

```
你是「私人专访编辑」——一个准备充分、犀利、有人味的访谈主持人。你不是语音助手，也不是客服。

【开场铁律 · 最重要】
- 你已经做足功课，现在直接开始。第一句话立刻进入正题：先用一句话点出"为什么现在和你聊这个"，紧接着抛出开场问题。
- 开场问题（口语化后直接问，别照念）：{suggestedOpening}
- 绝对禁止：寒暄（"你好吗/最近怎么样/过得好吗"）、自我介绍、元话语（"我刚来/还没准备好/没来得及/让我想想"）。

【本次准备】
- 主题：{title}　- 为什么现在聊：{whyNow}
- 可引用的历史原话：{historyReferences}
- 待追问的知识债 / 盲区：{debtToAddress｜blindspot}
- 推荐视角：{recommendedPerspectives}

【追问铁律 · 每轮都用】
- 每次只问一个核心问题。
- 对方抛出有分量但含糊的词，立刻钉住它追（"你说的 X 是什么意思？"）。
- 概括性回答必须追到具体："最近一次是什么时候？能举个例子吗？数字是多少？"
- 对方想"两者都有"时，给二选一框架逼他选边或反驳。
- 抓矛盾：对方现在说的和刚才说的 / 已知的有张力时，直接点出"但你刚才说…"。
- 对方说完一段，用一句话替他总结抛回去让他确认或纠正。

【语音节奏】
- 短回应、多留白；对方在说就不要抢话；对方一打断立刻停。
- 不长篇、不替对方下结论、不像客服。
```

**P0-2 合并两份 `buildRealtimeVoiceInstructions`**：删掉 `App.tsx` 的瘦本地副本，统一用 `src/domain/voice-instructions.ts` 的版本（按上面的结构升级它），让历史/知识债/盲区/记忆真正进 prompt。顺带给它补单测（注入 card+guide，断言 prompt 含开场脚本 + 禁寒暄句 + 历史引用）。

**P0-3（可选但推荐）把开场显式脚本化**：除了 prompt 约束，建会话时可由服务端直接给出"开场台词"（基于 whyNow + suggestedOpening 合成一句），客户端把它作为 AI 的第一条消息播报，**完全不依赖模型即兴**。这是最稳的反"你过得怎么样"方案。

**验收**：起语音 → AI 第一句是"为什么现在聊 + 开场问题"，无任何"怎么样/我刚来"；连说 2-3 轮，追问可见地钉具体/抓矛盾。

---

### P1 —— 把 10 条技法编进"文字 + 语音"共用的主持人 prompt

文字专访的系统 prompt 在 `apps/api/src/providers/bailian.ts` 的 `buildCharacterSystemPrompt`，语音在上面的 voice-instructions。两边共用一套"张小珺式追问铁律"（把第二节的 1–10 + 两条贯穿铁律落成 prompt 段落）。重点补齐现在缺的：单词回弹、二选一框架、抓矛盾、总结打点、身份锚点、"我不懂但具体问"。

建议把这套铁律抽成一个常量（如 `INTERVIEWER_CRAFT_RULES`），文字/语音/pre_signals 三处复用，避免又分叉。

---

### P2 —— 让技法"有数据可依"（支撑层）

技法不是光靠 prompt 喊口号，要有数据喂：
- **抓矛盾 / 引用历史**：语音/文字每轮都要把**本场已说过的话** + **历史原话**塞进上下文（现在瘦语音 prompt 把历史丢了 → P0-2 修）。
- **开场旁白要具体**：`whyNow / suggestedOpening / historyReferences` 的质量决定开场质感。确保 card/guide 生成的是**具体事实**而非套话（P4-T1 已去硬编码，这里再检查真实 key 下的产出质量）。
- **结构弧线**：给 session 加一个轻量"阶段"标记（热身→深挖→张力→收尾），prompt 按阶段切换追问策略 + 在转段时显式宣告（"那接下来，我们聊聊…"）。
- **不允许'很难说'结束**：pre_signals / 追问逻辑里加一条——侦测到对方"说不定/很难说"就触发二选一或具体条件追问。

---

### P3 —— 验证

- 语音手动实测（真 key）：开场无寒暄、追问钉具体、抓到至少一次矛盾、转段有显式宣告。
- 文字侧加真 LLM gated E2E：跑一段对话，断言追问里出现"具体事例/二选一/但你刚才说"的模式特征（可用关键词或 LLM-judge）。
- 回归：现有 426 vitest + 17 Playwright 全绿。

---

## 四、落地顺序建议

1. **先做 P0**（语音开场）——这是用户当下最痛、最高杠杆、半天可完成。
2. P1（共用技法 prompt）——让文字和语音一起变"像张小珺"。
3. P2（支撑数据/阶段）——把技法做实，不只是口号。
4. P3 验证 + 真 key 实测。

> 核心心法（来自张小珺）：**好的专访不是"礼貌地聊天"，是"带着功课，一句话进正题，每个含糊词都钉住，每个矛盾都点破，每段都替对方总结一遍"。** 产品现在缺的正是"带着功课 + 不寒暄 + 钉具体 + 抓矛盾"这四件事。
